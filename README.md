# steam-data-visualization

An interactive exploratory data visualization dashboard built with **Streamlit** and **Plotly** analyzing ~88k Steam games.

---

## 🚀 Setup & Installation Guide

Follow the steps below according to your operating system to set up your local environment.

### 1. Clone the Repository
```bash
git clone <YOUR_REPOSITORY_URL>
cd steam-analysis
```

---

### 2. Create and Activate a Virtual Environment

#### 🐧 Linux / 🍏 macOS
```bash
# 1. Create virtual environment
python3 -m venv .venv

# 2. Activate virtual environment
source .venv/bin/activate
```

#### 🪟 Windows
*Using Command Prompt (CMD):*
```cmd
python -m venv .venv
.venv\Scripts\activate.bat
```

---

### 3. Install Dependencies

Install the verified cross-platform packages:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

---

### 4. Running the Dashboard

Launch the Streamlit web application:
```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.
